Prompt Later — AI Chat Scheduler

Free · unlisted beta draft

Store description

Send later for your AI chats. Choose an existing conversation, a time, and a message. Prompt Later attempts to send your message to that saved conversation while your browser is running and your computer is awake. FEATURES - Capture the current conversation URL or paste one. - See attention counts on the toolbar when delivery needs review. - Schedule once: in five hours, in one minute for testing, or at a chosen date and time. - Repeat every N hours, daily, on weekdays, or using a five-field cron expression and time zone. - Save multiple messages, edit schedules, pause jobs, and review delivery activity. - Reuse the matching conversation tab or open it in the background without switching your active tab. - Choose whether an existing composer draft is preserved, sent, or replaced; the safe default preserves it and skips that occurrence. - Never repeat a one-off after sending may have started. If the browser interrupts an attempt before that boundary, Prompt Later may safely resume it and still applies the chosen late-run policy. Recurring schedules continue with their next occurrence after a blocked, skipped, or uncertain run. LOCAL ENCRYPTION, NO EXTRA SIGN-IN Saved messages, conversation URLs, schedules, and activity are automatically encrypted locally with AES-256-GCM using a browser-held non-exportable device key. No passphrase is required and there is nothing to unlock, so schedules resume by themselves after browser restarts and extension updates. Someone controlling the browser or profile may still access the data. You can review how this works under Advanced privacy in the full dashboard. No extra account, extension backend, telemetry, or AI API key is required. Messages are delivered through the provider website using your existing signed-in account. The provider processes messages under its own terms and privacy policy. BETA COMPATIBILITY ChatGPT and Claude integrations are supported. Additional AI chat integrations are experimental. Automated tests use simulated provider pages; they do not guarantee live compatibility. Website changes, login state, and account limits can prevent delivery. IMPORTANT LIMITS Keep the browser running and the computer awake. Turning off the monitor is fine. Alarms can be delayed and cannot wake the computer. The five-hour option is a convenience delay, not quota-reset detection. Prompt Later does not bypass account limits or guarantee that an AI will finish its work. Sent means that the page acknowledged the message, not that the response is complete. Prompt Later is an independent utility and is not affiliated with the supported AI providers.

Single purpose

Schedule user-written text messages for delivery to specific existing conversations on supported AI chat websites.

Permission justifications

storage
Store encrypted schedules, target URLs, messages, and activity locally. A non-exportable AES-256-GCM CryptoKey is kept in extension-origin IndexedDB for automatic device protection. Local and session extension storage are restricted to trusted extension contexts.
alarms
Wake the background service worker to check the next scheduled delivery while the browser is running. Chrome's alarm system holds the next wake-up time.
activeTab
Read the current tab URL when the user opens the extension or chooses Use current tab, so they can select that conversation without pasting its URL.
scripting
Inject packaged delivery code into the exact saved conversation after site access is granted. Inspect the composer, apply the selected existing-draft behavior, insert configured text when required, activate explicit send controls, and confirm acknowledgement. All injected code runs in an isolated world and is bundled in the package.
optional_host_permissions
Request access only to a provider site chosen by the user. Use granted access to locate the matching conversation tab, open that exact saved URL if necessary, and perform guarded delivery. Access is optional and is not requested for unrelated websites.

Remote code

All extension logic is packaged locally. It interacts with existing provider pages; it does not fetch or evaluate executable code from a server.

Reviewer instructions

  1. Install the beta into a separate test browser profile. The scheduler opens immediately with no passphrase and no onboarding. No Prompt Later account or API key is required; automatic local device encryption is configured on first use.
  2. Sign in to a supported AI website with a disposable test account or a reviewer-controlled account. Open an existing disposable ChatGPT conversation, finish any response, and leave its composer empty.
  3. Open Prompt Later, use the current tab or paste that conversation URL, and grant access only to that site. Check page should inspect readiness without typing or sending.
  4. Choose In 1 minute (test) and enter: This is a Prompt Later beta test. Reply with OK. Save, close the popup, and switch to another tab while leaving the browser running.
  5. The scheduled message should appear once in the saved conversation. Activity should record Sent only after page acknowledgement. Inspect any blocked or uncertain explanation instead of scheduling duplicates.
  6. For the default draft protection behavior, schedule another message and type an unsent draft in the target chat before it is due. The draft must remain untouched. A one-off job should need attention and a recurring job should keep its next occurrence scheduled. Delivery settings also offer explicit choices to send or replace a draft; test those choices only with disposable text.
  7. Experimental integrations are not a claim of live compatibility. No provider credentials are included in this draft; use only reviewer-controlled accounts.
