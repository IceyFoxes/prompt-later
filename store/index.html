Prompt Later

Free · unlisted beta draft

Store description

Send later for your AI chats. Choose an existing conversation, a time, and a message. Prompt Later attempts to send your message to that saved conversation while your browser is running and your computer is awake. FEATURES - Capture the current conversation URL or paste one. - Schedule once: in five hours, in one minute for testing, or at a chosen date and time. - Repeat every N hours, daily, on weekdays, or using a five-field cron expression and time zone. - Save multiple messages, edit schedules, pause jobs, and review delivery activity. - Reuse the matching conversation tab or open it in the background without switching your active tab. - Preserve existing drafts and block sending when the page is busy or controls are ambiguous. - Report uncertain delivery instead of automatically retrying a potentially completed send. LOCAL PASSPHRASE VAULT Saved messages, conversation URLs, schedules, and activity are encrypted locally. Create a passphrase and unlock again after a browser restart or extension update. Scheduled sending is paused while locked. Unlocking applies each job's late policy, so overdue messages may send immediately. There is no passphrase recovery service. No extra account, extension backend, telemetry, or AI API key is required. Messages are delivered through the provider website using your existing signed-in account. The provider processes messages under its own terms and privacy policy. BETA COMPATIBILITY Integrations are included for ChatGPT and Claude. Devin, Gemini, Grok, DeepSeek, Kimi, Perplexity, Microsoft Copilot, Qwen, and Mistral Le Chat are experimental. Automated tests use simulated provider pages; they do not guarantee live compatibility. Website changes, login state, and account limits can prevent delivery. IMPORTANT LIMITS Keep the browser running, the computer awake, and the vault unlocked. Turning off the monitor is fine. Alarms can be delayed and cannot wake the computer. The five-hour option is a convenience delay, not quota-reset detection. Prompt Later does not bypass account limits or guarantee that an AI will finish its work. Sent means that the page acknowledged the message, not that the response is complete. Prompt Later is an independent utility and is not affiliated with the supported AI providers.

Single purpose

Schedule user-written text messages for delivery to specific existing conversations on supported AI chat websites.

Permission justifications

storage
Store encrypted schedules, target URLs, messages, and activity locally. Keep the derived unlock key only in memory in chrome.storage.session while the extension remains loaded. Neither area is exposed to content scripts.
alarms
Wake the background service worker to check the next scheduled delivery while the browser is running. Chrome's alarm system holds the next wake-up time.
activeTab
Read the current tab URL when the user opens the extension or chooses Use current tab, so they can select that conversation without pasting its URL.
scripting
Inject packaged delivery code into the exact saved conversation after site access is granted. Check the composer, preserve drafts, insert the configured text, activate the explicit send control, and confirm acknowledgement. Grok's supported rich-text editor also requires a guarded main-world call to its existing editor API.
optional_host_permissions
Request access only to a provider site chosen by the user. Use granted access to locate the matching conversation tab, open that exact saved URL if necessary, and perform guarded delivery. Access is optional and is not requested for unrelated websites.

Remote code

All extension logic is packaged locally. It interacts with existing provider pages; it does not fetch or evaluate executable code from a server.

Reviewer instructions

  1. Install the beta into a separate test browser profile. Create a local vault passphrase of at least 12 characters; no Prompt Later account or API key is required.
  2. Sign in to a supported AI website with a disposable test account or a reviewer-controlled account. Open an existing disposable ChatGPT conversation, finish any response, and leave its composer empty.
  3. Open Prompt Later, use the current tab or paste that conversation URL, and grant access only to that site. Check page should inspect readiness without typing or sending.
  4. Choose In 1 minute and enter: This is a Prompt Later beta test. Reply with OK. Save, close the popup, and switch to another tab while leaving the browser running and vault unlocked.
  5. The scheduled message should appear once in the saved conversation. Activity should record Sent only after page acknowledgement. Inspect any blocked or uncertain explanation instead of scheduling duplicates.
  6. For draft protection, schedule another message and type an unsent draft in the target chat before it is due. The draft must remain untouched and the job should need attention.
  7. Restart the browser. The vault must be locked and automatic delivery paused. Entering the correct passphrase resumes schedules according to their saved late policies. An incorrect passphrase must not reset saved jobs.
  8. Experimental integrations are not a claim of live compatibility. No provider credentials are included in this draft; use only reviewer-controlled accounts.
